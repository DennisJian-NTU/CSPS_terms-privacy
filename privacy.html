隱私權政策

我們蒐集什麼資料？ 01
核心原則：「日常系超能保衛隊」以隱私優先為設計原則。我們不蒐集、不儲存您的個人識別資訊，也不需要您提供電子郵件、姓名或帳號。

以下是各類資料的詳細說明：

資料類型 儲存位置 我們能存取嗎？
日記內容與照片 您的裝置本機 ❌ 無法存取
收支帳目 您的裝置本機 ❌ 無法存取
行程與待辦事項 您的裝置本機 ❌ 無法存取
衣物清單資料 您的裝置本機 ❌ 無法存取
好感度與使用紀錄 您的裝置本機 ❌ 無法存取
衣物照片（AI辨識用） 暫時傳送至代理伺服器 ⚠️ 僅暫時傳輸（見下方說明）
🤖
AI 功能與資料傳輸 02

本 App 有三項功能需透過網路連線，資料會傳輸至我們的後端代理伺服器：

功能 傳輸內容 第三方服務
衣物照片辨識 衣物照片（base64）、衣物類型 Anthropic Claude API
穿搭建議 天氣、心情、場合、衣物 ID 列表 Anthropic Claude API
每日小語 生成請求（無個人資料） Anthropic Claude API
代理架構說明：所有 AI 請求均透過我們部署在 Vercel 的後端代理轉發，您的裝置不會直接與 Anthropic 通訊。API 金鑰僅存於伺服器端。上傳的衣物照片僅用於當次辨識，不會被永久儲存或用於其他目的。

Anthropic 的隱私政策請參閱：anthropic.com/privacy

本 App 可能請求以下裝置權限：

權限 用途 必要性

資料安全 04

我們採取以下措施保護您的資料安全：

  • 本機儲存優先：日記、帳目等敏感個人資料完全儲存在您的裝置，不上傳至任何伺服器
  • 傳輸加密：所有網路通訊均透過 HTTPS 加密傳輸
  • API 金鑰保護：Claude API 金鑰僅存於後端，絕不暴露於客戶端程式碼
  • 圖片壓縮：上傳的衣物照片在傳輸前會壓縮處理，減少不必要的資料量
  • 無追蹤機制：本 App 不含廣告追蹤器、分析 SDK 或任何第三方追蹤程式碼
本機資料保護：您裝置本機的資料安全由您的裝置鎖定機制（Face ID、密碼等）提供保護。建議您啟用裝置鎖定功能以保護個人資料。
👶
兒童隱私 05

本 App 適合一般大眾使用，未對特定年齡層進行限制。由於我們不蒐集任何個人識別資訊，亦不設有需要驗證年齡的帳號系統，因此不存在蒐集兒童個人資料的情形。

若您是未成年用戶，建議在家長或監護人的陪同下使用 AI 相關功能。

🗑️
資料刪除 06

由於所有個人資料均儲存於您的裝置本機，您可透過以下方式管理或刪除資料：

  • 刪除單筆資料：在 App 內各工具頁面直接滑動刪除（支援左滑快速刪除）
  • 清除全部資料：從您的裝置解除安裝本 App，將永久移除所有本機資料
  • AI 傳輸資料：上傳的衣物照片僅用於當次辨識，處理完成後即不保留於我們的伺服器
由於本 App 不蒐集個人識別資訊、不設帳號，我們的伺服器端沒有任何可供刪除的個人資料。
